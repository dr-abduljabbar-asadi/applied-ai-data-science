METRICS BY TASK (use the right ones for {TASK_TYPE})

--------------------------------------------------------------------------------
VISUALISATION RULES (apply throughout)
--------------------------------------------------------------------------------
- Choose the BEST library per chart; don't default to one:
    * Plotly for INTERACTIVE EDA/results (corrplot, marginal scatters,
      actual-vs-predicted, feature importance, confusion matrix).
    * Matplotlib for custom model plots, decision boundaries, and ALL animations.
    * Seaborn for quick statistical distributions/scatters.
- Every chart: clear title, axis labels, readable colours, a short
  interpretation and a "Key insight" line.
- CENTER all Plotly titles:  title=dict(x=0.5, xanchor="center")
  (the plotly_white template left-aligns titles by default).
- Bar charts: sort by magnitude, add value labels, de-clutter spines, light grid
  behind the bars, and a legend explaining colours.
- Comparison plots (actual-vs-predicted): equal aspect + matched ranges so the
  reference line is fair; annotate the metric(s) on the chart.
- Animations: render inline via HTML(anim.to_jshtml()) (no ffmpeg needed);
  plt.close(fig) before displaying to avoid a duplicate static figure; keep
  steps small enough that progress is visible.
- Interactive Plotly animations (play button + slider): build with go.Figure +
  frames + updatemenus (an animate button) + sliders; in each frame update ONLY
  the traces that change (pass traces=[...]) so static elements (e.g. a surface)
  don't flicker; centre the title. Use these for 3-D loss surfaces and
  hyperparameter explorers.
- NOTE ON GITHUB: Plotly interactives render in VS Code/Jupyter but NOT in
  GitHub's static .ipynb preview. If the notebook must look good on GitHub too,
  offer a static image fallback.
